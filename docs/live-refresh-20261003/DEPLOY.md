## Safe secret loading example (Node service wrapper)

Use child_process.execFileSync('gcloud', ['secrets','versions','access','latest','--secret=<NAME>','--project=forest-family-cloud'], { encoding: 'utf8', stdio: ['ignore','pipe','ignore'] }).trim() and assign the result to the server's environment in memory, then import scripts/serve-catalogue.mjs. Do not console.log the value, command-substitute it into printed commands, or place it in browser code. The service account needs only access to its named secrets. This wrapper example describes the deployment prerequisite; no credentials or secret values are committed.
