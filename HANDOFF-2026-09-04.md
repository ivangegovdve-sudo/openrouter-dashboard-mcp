**The guard that prevents recurrence** is `test/readme-truth.test.ts`. It reads tool names from the **live server** over a real MCP `tools/list` and providers from `PROVIDER_REGISTRY` — both sides are the thing being described, not a restatement. Two earlier versions were rejected in review: a source-regex scan (a variable-named registration is invisible to a grep) and prefix matching (`dashboard_foo-v2` compared equal to `dashboard_foo`). Both failure modes were reproduced before being fixed.

Known, accepted, not blocking: `tools/list` pagination is ignored (ten tools, synchronously registered, no `nextCursor`), and the provider check is one-way — a provider removed from the registry but left in the README would not fail. Exact set equality is the follow-up.

## Traps worth knowing

- **`core.autocrlf=true` in `openrouter-dashboard-mcp`.** `sail-pricing.md` is hashed byte-for-byte. Git was rewriting its 1,618 LF line endings on checkout — a fresh clone gave 66,180 bytes instead of 64,562 and a completely different digest, which surfaced as `PRICES ARE STALE` on a tree where nothing was wrong. Fixed with `sail-pricing.md -text` in `.gitattributes`. **Any other byte-digested fixture needs the same.**
- **The test suite is flaky under memory pressure, and this machine is short on memory.** Eight full runs of an unchanged dashboard tree gave 124 files seven times and 121 once. In `openrouter-dashboard-mcp`, eight runs gave 206/206 seven times and once collapsed to **49 tests with 19 failures** — most files never ran. Minutes later `git push` died with `fatal: Out of memory` and `cannot spawn git-remote-https`, which strongly suggests the flakiness is resource exhaustion rather than test logic. A single green run proves nothing; run three, and re-run rather than trusting a bad one. **Ivan is having RAM-adjacent hardware fitted, so this may simply go away.**
- **No CI in either repo.** No `.github/workflows`. A green checkmark on a PR means no conflicts, nothing more.
- **`prepublishOnly` is advisory.** 0.5.1 shipped from a tree where a Sail test was already failing, so the gate has been routed around at least once.
